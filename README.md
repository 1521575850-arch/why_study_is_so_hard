# C 语言学习代码与笔记

C 语言学习过程中的代码和笔记整理，方便老师检查学习情况。

## 目录结构

```
├─ 主机代码/          # 在 Windows 主机上编写
│  ├─ Basic_C_Language_Exercises/   # C 语言基础练习（1.c ~ 7.c）
│  ├─ C_Language_Study_Document/    # C 语言学习文档与笔记
│  ├─ StudentSystem/                # 学生管理系统（分层：接口/队列/栈）
│  └─ STUDENT_MANAGEMENT_SYSTEM_PRO # 学生管理系统进阶项目
└─ 虚拟机代码/        # 在 Ubuntu 虚拟机上编写
   ├─ 标准IO函数一/    # fopen/fclose/fgetc/fputc/fgets/fputs 等
   ├─ 标准IO函数二/    # fread/fwrite/feof/ferror 等
   ├─ 文件IO函数一/
   ├─ 文件IO函数二/
   └─ buffer/         # 缓冲区练习（setbuf/setvbuf 等）
```

## 说明

- 全部代码均为 C 语言学习练习
- 编译产物（.exe / 可执行文件）已通过 `.gitignore` 排除，只保留源码
- 每个目录下的 `.c` 文件按序号排列，可对照学习进度查看
